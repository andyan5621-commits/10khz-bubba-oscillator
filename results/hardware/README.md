# Hardware result transcriptions

- [PCB amplitude sweep](pcb-amplitude-sweep.csv): seven user-reported rows; spectral values are provisional estimates.
- [Breadboard amplitude sweep](breadboard-amplitude-sweep.csv): nine historical rows with original cursor-separation heading.
- [PCB repeat captures](pcb-repeat-captures.csv): screenshot readouts, actual displayed sample rate 180.18 kS/s.

These CSVs are manual transcriptions, not raw ADC recordings. Vpp is calculated as 2 × Vpk. Compare like amplitudes and do not infer calibrated SFDR, uncertainty or timed stability. See the [final report](../../docs/report/final-project-report.md), [measurement log](../../pcb/R1/reports/hardware-measurement-log.md) and [original evidence](../../evidence/hardware/2026-11-20/README.md).
