# Clear R1 component map

Use `R1-clear-component-map.pdf` for identifying parts during assembly. The six pages show the board overview, left resistors, four timing chains, output resistors, other components and all eight test points. Colored leader lines end at a dot on the named component or its pad; original crowded silkscreen text is deliberately omitted.

All views are from the component side, with the board title upright and BNC on the right. They are enlarged identification views, not scale templates. PNG and SVG copies of each page are included.

Generated by `assembly/create_clear_map.py` from the frozen R1-review-03 native board. All 44 fixed resistor labels and values are checked against the per-component BOM. `map-provenance.json` records the source identity. The actual PCB and production files are not edited by this script.

Physical assembly or rework status is not established by the map. In particular, the previously reported 10 kOhm part at R801 must be corrected to 300 kOhm and inspected before power-up; the builder subsequently reported that repair completed. See the final hardware measurement log.
