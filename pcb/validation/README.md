# Validation

The assembled R1 board's [hardware measurement log](../R1/reports/hardware-measurement-log.md), [CSV results](../../results/hardware/README.md), [original spectra](../../evidence/hardware/2026-11-20/README.md) and [project closeout](../R1/reports/project-closeout.md) document functional operation and preliminary spectral evaluation.

The [final report](../../docs/report/final-project-report.md) separates hardware evidence from simulation. Approximately 10.006 kHz operation and output adjustment were demonstrated; intrinsic SFDR, timed drift and quantified startup remain unqualified. The [independent design review](../R1/verification/independent-review.md) is a pre-fabrication engineering record, not an independent physical test.
